## Compilar

Subir a GitHub, revisar Actions -> Compilar MatchBoard v3.3. Genera `app-debug.apk`. Para Play Store hay que completar firma y AAB de publicación. Los diseños del marcador y los mapeos iniciales SN30 permanecen sin cambios.
