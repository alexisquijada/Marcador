Configuración

Toca el puntaje para sumar. Mantén pulsado el puntaje rojo o azul para corregir el último punto si fue de ese equipo. Para abrir este menú, mantén pulsada la hora. Toca la pelota para indicar quién saca.

Teclado: 1 suma al rojo, 2 al azul, Q marca saque rojo, W marca saque azul, Z deshace, M abre el menú.

Para asignar botones, toca una acción y pulsa el botón físico del mando. Los valores iniciales son los del SN30:

Compatible con mandos reconocidos por Android como controles de juego HID, incluidos Bluetooth y USB. Predeterminados: X/B rojo, A/Y azul, SELECT bloqueo. Conecta desde Ajustes de Android y pulsa el botón que deseas asociar. Las asignaciones se guardan; puedes restaurar los valores originales. Se aceptan varios mandos conectados, pero en esta versión todos comparten las mismas acciones.
